# موقع مطبخ سوبر محشي

## الملفات
- `index.html`: صفحة الموقع
- `styles.css`: التصميم المتجاوب
- `app.js`: زر تثبيت الموقع كتطبيق
- `manifest.webmanifest` و`service-worker.js`: دعم تطبيق الويب التقدمي (PWA)
- `assets/logo.png`: ضع شعار المطبخ هنا باسم `logo.png`

## النشر على GitHub Pages
1. ارفع محتويات هذا المجلد إلى مستودع GitHub (يفضل أن يكون المستودع الذي تنشر منه الموقع).
2. ضع الشعار في مجلد `assets` باسم `logo.png`، ويفضل أن يكون مربعًا وعالي الجودة.
3. من Settings > Pages اختر فرع النشر ومجلد الجذر `/root` ثم Save.
4. افتح رابط الموقع من الهاتف. على Android استخدم قائمة المتصفح ثم "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية". على iPhone افتح الرابط في Safari ثم Share > Add to Home Screen.

ملاحظة: ظهور زر التثبيت داخل الصفحة يعتمد على المتصفح والجهاز، لكن يمكن تثبيت الموقع يدويًا من قائمة المتصفح. يجب نشر الموقع عبر HTTPS حتى تعمل ميزات PWA.
